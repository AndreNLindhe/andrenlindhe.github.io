2. Det här ska sitta

  • Du kan följa en förfrågan hela vägen: adressfältet, DNS, request, svar, statuskod.
  • Du kan säga vad som är statiskt innehåll och vad som skapas på servern vid varje förfrågan.
  • Du kan peka ut filerna i ditt Blazor-projekt och säga vad var och en gör.
  • Du kan starta projektet, ändra i det och pusha ändringen till GitHub.
  • Du vet varför Å, Ä och Ö ibland blir frågetecken, och hur du undviker det.

3. Kom igång

Det här gjorde vi på lektion 1. Har du missat passet, eller bytt dator, gör du samma sak igen.

Har du missat ett senare pass tar du igen det i guiden. Den går hela vägen från tomt projekt till färdig sajt, med all kod, och varje referenssida säger överst vad du ska göra om du var borta.

Skapa repot tomt

När du skapar repot på github.com: bocka inte i "Add a README file", ingen .gitignore och ingen licens. Ett repo som redan har en fil vägrar ta emot din första push, och felmeddelandet berättar inte varför.

StegDet du gör
1Logga in på github.com och skapa ett tomt, publikt repo som heter webbresan.
2Kör en gång per dator: git config --global user.name "Ditt Namn" och git config --global user.email "din.skolmejl@exempel.se"
3Skapa projektet: dotnet new blazor -o Webbresan -int None
4Gå in i mappen och kör det: cd Webbresan och dotnet run
5Öppna adressen terminalen skriver ut. "Hello, world!" ska synas.
6Stoppa servern med Ctrl+C och koppla på GitHub: git init, git add ., git commit -m "Första körningen", git branch -M main, git remote add origin …, git push -u origin main
Prova själv

Be en klasskamrat om adressen till deras körande projekt och försök öppna den. Det går inte. Det är innebörden av localhost: den här datorn, ingen annan.

4. Så lämnar du in

Koden ligger på GitHub. itslearning tar emot länken till den. Kort version: kontrollera att projektet startar, gå igenom kraven, committa och pusha, och klistra in repots adress i itslearning.

Hela ordningen, kamratgranskningen och det som brukar gå fel den sista timmen står på Lämna in. Läs den innan du pushar sista gången.

Committa löpande under arbetets gång, inte allt sista kvällen. Antalet commits är ett krav i uppgiften just därför – historiken visar när du arbetade, inte bara att du gjorde det.

Orden nedan används från och med nu utan förklaring. Träna tills du kan dem.

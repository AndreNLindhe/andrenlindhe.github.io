Driftsättning, API och externa data

Applikationen lämnar din dator. Den får en riktig adress med HTTPS, där andra kan nå den, och den lär sig prata med andra servrar: den hämtar data från ett externt API, och har ett eget som svarar med JSON. Området är kort och intensivt – och ligger före slutprojektet med avsikt, så att ingen driftsätter för första gången kvällen före sista inlämningen.

  • 20 april Driftsatt – alla, under passet Etapp 1, driftklar på din egen dator, ska vara klar före passet.
  • 28 april Redovisning: applikationerna live Tre minuter var, på din adress.
  • 2 maj Projekt 3 – Driftsatt applikation med API-funktion, kl 23:59 Adressen och repots adress lämnas i itslearning. Inget prov – applikationen och redovisningen är examinationen.

2. Det här ska sitta

  • Du kan säga vad som skiljer Development från Production i ditt projekt, och varför user-secrets inte finns på servern.
  • Du kan skriva en inställning som miljövariabel, med dubbla understreck.
  • Du kan förklara varför driften provas med det publicerade programmet, och inte med dotnet run.
  • Du kan driftsätta din applikation så att någon annan kan göra om det efter din beskrivning.
  • Du kan läsa ett REST-anrop: resurs, metod, statuskod och innehåll.
  • Du kan förklara varför ett API lämnar ut ett eget svarsobjekt och inte entiteten, och varför ett fel från ett API ska vara JSON.
  • Du kan säga vad som händer med din sida när ett externt API inte svarar, och vad tidsgränsen gör.
  • Du kan visa att inga lösenord ligger i ditt repo – nu eller i historiken.

6. Orden

Orden nedan används från och med nu utan förklaring, och kommer tillbaka i slutprovet.

Ordträning

OrdBetyder
miljöDevelopment på din dator, Production på servern. Styrs av ASPNETCORE_ENVIRONMENT.
miljövariabelEn inställning som operativsystemet ger programmet när det startar. Ligger utanför koden och utanför repot.
dotnet publishBygger det som ska köras på servern – utan källkod, utan testprojekt.
driftsättningAtt få en applikation att köra på en server, åtkomlig för andra.
App ServiceAzures tjänst för webbapplikationer. Du lämnar programmet, Azure kör det.
loggDet applikationen skriver om vad den gör. I drift det enda stället där ett fel syns.
APIApplication Programming Interface – ett gränssnitt som program anropar, inte människor.
RESTEtt sätt att bygga API:er: adresserna är resurser, och HTTP-metoden säger vad som ska göras.
JSONTextformatet API:er oftast svarar med. {"titel":"Gökboet","ar":1975}.
statuskodSiffran i svaret som säger hur det gick. 200 gick bra, 404 finns inte, 500 servern föll.
problem detailsStandardformen för ett fel i ett JSON-API: typ, rubrik, statuskod och förklaring.
HttpClientKlassen som skickar förfrågningar från din server till en annan.
typad klientEn egen klass som får en färdig HttpClient injicerad, registrerad med AddHttpClient.
tidsgränsHur länge HttpClient väntar på ett svar innan den ger upp. Förvalet är 100 sekunder.
svarsobjektDet ett API lämnar ut, i stället för entiteten. Bestämmer vilka fält som blir offentliga.

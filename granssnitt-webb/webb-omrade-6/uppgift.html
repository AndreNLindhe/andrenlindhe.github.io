Projekt 5 – Interaktiv sajt

Deadline tisdag 16 mars kl 23:59. Samma sajt som i Projekt 4, nu med ljuden och mikrointeraktionerna från Gränssnittsdesign.

1. Uppdraget

Du ska bygga in ljuden och mikrointeraktionerna från Gränssnittsdesign i din sajt, med JavaScript, webbens programmeringsspråk. Samma sajt som i Projekt 4, nu med beteende.

Det här är första gången i kursen du skriver kod som gör något i stället för att vara något. HTML säger vad som finns, CSS hur det ser ut, JavaScript vad som händer när någon använder det. De tre ska hållas isär, och det är ett krav, inte en stilfråga.

Sajten ska fungera fullt ut med JavaScript avstängt. All information går att läsa, alla länkar och formulär fungerar. Det enda som saknas utan JavaScript är ljudet och de tillstånd som bara JavaScript kan sätta. JavaScript lägger till, det bär aldrig.

Uppgiften är en trappa. Du börjar med kod du inte skrivit själv och slutar, om du siktar högt, med kod någon annan kan använda:

Rörelsen görs i CSS. JavaScript byter bara läge. En knapp som visar att den skickar får en klass av JavaScript, och det är CSS som sköter hur den klassen ser ut och hur övergången går. Då fungerar rörelsen för sig, och JavaScript-koden blir kort.

8. Kom igång

  1. Skriv upp vad som fungerar på din sajt, första passet: innehållet, länkarna, formuläret. Sajten har ingen JavaScript än, så listan är sajten utan JavaScript. Det är din nollpunkt, och allt på den ska fungera på deadlinedagen med JavaScript avstängt.
  2. Koppla in en tom skriptfil som skriver i konsolen. En rad, console.log("skriptet laddades"). Syns raden i konsolen på varje sida är sökvägen och defer rätt innan du skrivit något som kan gå fel.
  3. Bygg en mikrointeraktion i CSS innan du skriver JavaScript. Gör klassen och övergången, och sätt klassen för hand i DevTools. Ser det rätt ut är det bara en rad JavaScript kvar.
  4. Ljuden sist, när överlämningen kommit den 8 mars. Modulen går att koppla in och prova med referensprojektets ljud före dess.

9. Vanliga misstag

  • onclick i HTML:en. Det fungerar, men det blandar ihop beteende och struktur. All JavaScript i .js-filer, kopplad med addEventListener.
  • Skriptet körs innan sidan finns. Utan defer letar skriptet efter element som inte är lästa än, och querySelector ger null. Felet står i konsolen.
  • Innehåll som bara JavaScript skapar. Text som skrivs in med JavaScript finns inte för den som har det avstängt, eller för sökmotorn. Innehållet hör hemma i HTML:en.
  • Rörelse satt med style i JavaScript. Då går den inte att stänga av med prefers-reduced-motion, och utseendet ligger på två ställen. Byt klass i stället.
  • Ljud som spelas när sidan laddas. Webbläsaren stoppar det, och det är rätt av den. Ljud spelas när användaren gör något.
  • Ljudknappen som bara är en ikon. Den som inte ser den vet inte vad den gör. Knappen ska säga vad den gör och om ljudet är på.
  • Namnbyten på ljudfilerna. Modulen hittar dem inte, och överlämningen stämmer inte längre.

Det första programmet

Ett program är instruktioner i ordning. Pico:n läser dem uppifrån och ner och gör exakt det som står, varken mer eller mindre. Det första programmet tänder och släcker en lysdiod – och det räcker för att förstå hur allt annat i blocket fungerar.

1. Blink

I VS Code: File → New File. Spara direkt som blink.py i mappen teknik1 (Ctrl+S). Skriv av programmet rad för rad – kopiera inte, det är genom att skriva du lär dig var tecknen sitter.

from machine import Pin
from time import sleep

led = Pin(25, Pin.OUT)

while True:
    led.on()
    sleep(0.5)
    led.off()
    sleep(0.5)
Indraget är inte pynt

Raderna under while True: har fyra mellanslag i början. Det är så Python vet att de hör till loopen. VS Code gör indraget själv när du trycker Enter efter kolonet – ta inte bort det.

3. Kör, stoppa, ändra

  1. Klicka Run nere i listen (eller Ctrl+Shift+P → MicroPico: Run current file on Pico). Den gröna lysdioden på kortet blinkar.
  2. Klicka Stop. Den slutar.
  3. Ändra 0.5 till 0.1 på båda ställena. Kör igen. Ändra till 2. Kör igen.
  4. Ta bort raden led.off(). Gissa vad som händer innan du kör.
Prova själv

Gör så att den lyser länge och är släckt kort. Sedan tvärtom. Du behöver bara ändra två tal.

4. Breadboarden

Breadboarden är en platta med hål där du kopplar ihop saker utan att löda. Det enda du måste veta:

  • De fem hålen i en rad sitter ihop elektriskt. Sätter du två ben i samma rad är de kopplade till varandra.
  • De långa raderna längs kanten sitter ihop på längden. De används för plus och minus.
  • Spåret i mitten delar plattan. Pico:n sätts över spåret så att benen hamnar på var sin sida – då kortsluts inte benen med varandra.
   a  b  c  d  e     f  g  h  i  j
1  o  o  o  o  o  |  o  o  o  o  o     ← a1–e1 sitter ihop. f1–j1 sitter ihop.
2  o  o  o  o  o  |  o  o  o  o  o        Men a1 och f1 gör det inte.

5. LED på pinne 15

Du behöver: en lysdiod, ett motstånd på 220 Ω (röd-röd-brun), två kopplingstrådar.

  1. Tråd från Pico:ns GP15 till en tom rad på breadboarden.
  2. Motståndet från den raden till en ny rad.
  3. Lysdiodens långa ben i motståndets rad. Det korta benet i en egen rad.
  4. Tråd från lysdiodens korta ben till GND på Pico:n.
Två regler

Motståndet är inte valfritt. Utan det brinner lysdioden efter en stund. Långt ben till plus. Lyser den inte: vänd lysdioden. Den går inte sönder av att sitta fel.

Sedan samma program med en siffra ändrad. Spara som blink15.py:

from machine import Pin
from time import sleep

led = Pin(15, Pin.OUT)

while True:
    led.on()
    sleep(0.5)
    led.off()
    sleep(0.5)

Kör. Nu blinkar lysdioden på breadboarden i stället för den på kortet. Samma kod, annan pinne – det är precis så roboten kommer att styras om tre veckor.

6. SOS – din första uppgift

SOS på morse är tre korta, tre långa, tre korta. Kort = 0,2 sekunder, lång = 0,6. Mellan varje blink är den släckt 0,2 sekunder.

Skriv det först med talen inskrivna överallt. Det blir många rader. Det är meningen.

När det fungerar: du vill göra hela mönstret dubbelt så snabbt. Hur många ställen måste du ändra på? Det är därför variabler finns. Skriv om programmet så här i början, och använd namnen i stället för talen:

from machine import Pin
from time import sleep

led = Pin(15, Pin.OUT)
kort = 0.2
lang = 0.6

while True:
    led.on()
    sleep(kort)
    led.off()
    sleep(kort)
    # … fortsätt själv: tre korta, tre långa, tre korta

Nu räcker det att ändra kort och lang på ett ställe.

Installation: VS Code och Pico:n

Det här gör du en gång. När det är klart skriver du kod i VS Code på din dator och Pico:n kör den direkt. Följ stegen i ordning – hoppa inte över steg 4, det är där du vet att allt fungerar.

1. Vad du behöver

  • Din dator, med rätt att installera program.
  • En Pico (RP2350-Plus) ur lådan. Den har redan rätt firmware – du behöver inte göra något med den.
  • En USB-kabel som klarar data, inte bara laddning. Kablarna i lådan gör det. En laddkabel hemifrån gör det ofta inte – då lyser Pico:n men datorn ser den inte.

2. VS Code och MicroPico

VS Code är programmet du skriver kod i. MicroPico är ett tillägg (en extension) som lär VS Code att prata med Pico:n.

  1. Har du inte VS Code: hämta från code.visualstudio.com och installera med alla förval.
  2. Öppna VS Code. Klicka på Extensions i vänsterkanten (ikonen med fyra rutor), eller tryck Ctrl+Shift+X.
  3. Sök på MicroPico. Klicka Install på tillägget som heter just så.
  4. Skapa en mapp på skrivbordet som heter teknik1. All kod i blocket ligger där.
  5. I VS Code: File → Open Folder → välj mappen teknik1. Svara Yes, I trust the authors om VS Code frågar – det är din egen mapp.

Mappen ser ut så här när blocket är slut. Just nu är den tom:

teknik1/
  blink.py
  sos.py
  logg.md
  …

3. Koppla in Pico:n

  1. Koppla kabeln mellan Pico:n och datorn. Windows piper till.
  2. Inget fönster ska öppnas. Öppnas ett fönster med filer i har du råkat hålla in knappen på Pico:n medan du kopplade in – dra ur och koppla in igen utan att röra knappen.
  3. Titta nere till vänster i VS Code. Där står Pico Disconnected. Klicka på texten. Den ska bli Pico Connected.
  4. Blir den inte det: tryck Ctrl+Shift+P, skriv MicroPico: Connect och tryck Enter.

4. Kvittot: hej

Nere i VS Code finns en terminal. Om den inte syns: View → Terminal. Skriv den här raden och tryck Enter:

print("hej")

Pico:n svarar:

hej
Nu är du klar

Det som hände: du skrev en rad Python, datorn skickade den till Pico:n, Pico:n körde den och skickade tillbaka svaret. Allt du gör resten av blocket är samma sak med längre program.

Klar före de andra? Hjälp paret bredvid. Nästa sida är det första programmet.

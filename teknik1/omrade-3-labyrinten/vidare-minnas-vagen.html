Vidare på egen hand

För dig som lånar hem en robot. Guiden har två delar. Den första tar dig från basen till en robot som hittar genom labyrinten – det vi gjorde pass 9, med all kod. Den andra går längre: roboten minns vägen den tog, stryker återvändsgränderna och kör den korta vägen andra gången.

Frivilligt, och inte bedömt

Det här ingår inte i projektet. Nivåerna E, C och A gäller det som står på projektsidan, och inget här ändrar på dem. All kod finns på sidan, i den ordning du skriver den. Kör du fast finns ett facit hos läraren – fråga.

Du behöver en bana

Svart eltejp på ett ljust golv eller ett stort vitt papper. Bara raka linjer och räta hörn. Ingen tvärlinje vid start. Målet är en svart ruta, minst 10 × 10 cm, av tejpremsor bredvid varandra. Minst en korsning, ett hörn och en återvändsgränd, och minst 15 cm mellan två korsningar.

7. En klocka

Hittills har roboten väntat med sleep. Medan den sover kan den inte läsa sensorerna. Nu ska den göra två saker samtidigt: köra en viss tid och titta. Då behövs en klocka. Ändra importraden högst upp i filen till:

from time import sleep, ticks_ms, ticks_diff
FunktionGör
ticks_ms()Svarar med hur många millisekunder som gått sedan Pico:n startade. En klocka som bara går
ticks_diff(now, start)Skillnaden mellan två klockslag, i millisekunder

Mönstret är alltid detsamma: läs av klockan när något börjar, och fråga sedan om och om igen hur lång tid som gått.

8. Titta under steget

När roboten kommer lite snett in i en korsning ser den ena sidans linje före den andra. Tittar den bara en gång kan den missa vägen åt vänster. Den här funktionen tar samma steg som step_forward(), men läser sensorerna hela vägen och kommer ihåg om vänstra sensorn såg tejp någon gång.

def step_and_look():
    left = False
    start = ticks_ms()
    forward(SPEED, SPEED)
    while ticks_diff(ticks_ms(), start) < STEP_TIME * 1000:
        position, values = sensor.readLine()
        if values[0] > DARK:
            left = True
    stop()
    return left

left börjar som False och blir True så fort vänstra sensorn ser svart. Den blir aldrig False igen – det räcker att linjen syntes en gång. STEP_TIME * 1000 gör om sekunder till millisekunder.

Efter steget behövs en fråga till: fortsätter linjen rakt fram?

def line_straight_ahead():
    position, values = sensor.readLine()
    return values[1] > DARK or values[2] > DARK or values[3] > DARK

9. Lämna korsningen

Direkt efter en sväng står roboten ofta lite snett, och en av yttersensorerna kan ligga kvar över tejpen i korsningen. Då tror roboten att det är en ny korsning och skriver upp ett val som inte finns. Därför följer den linjen en liten stund, tills båda yttersensorerna ser vitt, innan den börjar leta efter nästa korsning.

def leave_crossing():
    start = ticks_ms()
    while True:
        position, values = sensor.readLine()
        follow_track(position)
        clear = values[0] < DARK and values[4] < DARK
        if clear and ticks_diff(ticks_ms(), start) > 200:
            break

clear är True när båda yttersta ser vitt. Loopen bryts när det stämmer och minst 200 millisekunder har gått.

11. Förkorta

Varje "U" i listan är en återvändsgränd som roboten gick in i och ut ur. Valet före, vändningen och valet efter kan bytas mot ett val. Vilket? Lägg ihop graderna för de tre och se vart roboten egentligen tog vägen:

L U L     270 + 180 + 270 = 720     720 är två hela varv = 0     S   rakt
L U S     270 + 180 + 0   = 450     ett varv och 90              R   höger
S U L       0 + 180 + 270 = 450     ett varv och 90              R   höger
L U R     270 + 180 + 90  = 540     ett varv och 180             U   vänd
S U S       0 + 180 + 0   = 180                                  U   vänd

Ett helt varv, 360 grader, ändrar ingenting. Därför räknas bara det som blir över. I Python heter det %: 450 % 360 är 90.

ANGLE = {"S": 0, "R": 90, "U": 180, "L": 270}
LETTER = {0: "S", 90: "R", 180: "U", 270: "L"}


def shorten(path):
    short = []
    for choice in path:
        short.append(choice)
        while len(short) >= 3 and short[-2] == "U":
            after = short.pop()
            short.pop()
            before = short.pop()
            total = (ANGLE[before] + 180 + ANGLE[after]) % 360
            short.append(LETTER[total])
    return short

12. Köra efter listan

Andra körningen ser ut som den första. Skillnaden är att roboten inte väljer i korsningarna. Den läser nästa bokstav ur listan.

def run_path(path):
    step = 0
    while True:
        position, values = sensor.readLine()
        line_side = values[0] > DARK or values[4] > DARK
        line_ahead = values[1] > DARK or values[2] > DARK or values[3] > DARK

        if line_side:
            step_and_look()
            if at_goal():
                return True
            if step >= len(path):
                return False
            choice = path[step]
            step = step + 1
            if choice == "L":
                turn_left_until_line()
            elif choice == "R":
                turn_right_until_line()
            leave_crossing()
        elif line_ahead:
            follow_track(position)
        else:
            return False
